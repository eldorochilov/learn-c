# 01-asoslarga

C tilining eng boshlang'ich, hamma narsa ustiga quriladigan mavzulari.

| Fayl | Mavzu |
|---|---|
| `01-sintaksis.c` | Dastur tuzilishi, main(), kommentlar, kompilyatsiya |
| `02-turlar.c` | Ma'lumot turlari va o'zgaruvchilar |
| `03-operatorlar.c` | Arifmetik, solishtirish, mantiqiy, bitwise operatorlar |
| `04-kirish-chiqish.c` | printf, scanf, format spesifikatorlari |
| `05-boshqaruv.c` | if/else, switch, while, for, break/continue |
| `06-funksiyalar.c` | Funksiya e'lon qilish, parametr, qaytish qiymati |
| `07-massivlar-satrlar.c` | Bir o'lchamli massivlar, C-string asoslari |
| `08-korsatkichlar.c` | Pointer asoslari (& va *), massiv-pointer aloqasi |

## Kompilyatsiya

Har bir faylni alohida sinab ko'rish uchun:

```bash
gcc 01-sintaksis.c -o dastur && ./dastur
```
