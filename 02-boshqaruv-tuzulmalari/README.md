# 02-boshqaruv-tuzilmalari

C tilida dastur oqimini (control flow) boshqaruvchi tuzilmalar -- chuqur va
amaliy misollar bilan.

| Fayl | Mavzu |
|---|---|
| `01-if-else.c` | if/else if/else, nested if, ternary operator |
| `02-switch.c` | switch-case, fall-through, default |
| `03-for.c` | for sikli, nested for |
| `04-while-do-while.c` | while va do-while chuqur qo'llanilishi |
| `05-break-continue-goto.c` | break, continue, goto/label |
| `06-amaliy-patternlar.c` | Menu, input validation, qidiruv patternlari |

## Kompilyatsiya

```bash
gcc 01-if-else.c -o dastur && ./dastur
```
